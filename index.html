الانتقال السريع في خط الزمن: 1880
حدة النغمة (Pitch)

ترتبط بدرجة حرارة السطح. الحرارة المنخفضة تعطي نغمات منخفضة (Bass) بينما الحرارة المرتفعة ترفع النغمة للأعلى.

إيقاع الكربون (Beats)

تزايد انبعاثات ثاني أكسيد الكربون (CO2) يضيف ضربات إيقاعية عميقة تزداد حدتها وسرعتها مع مرور السنوات.

التجاوب البصري

تتغير ألوان المخطط والهالة المركزية بحسب الحالة المناخية (أزرق للمعتدل، وأحمر للارتفاع القياسي).

خطوات نشر هذا المشروع على GitHub Pages مجاناً

اتبع هذه الخطوات البسيطة لجعل هذا التطبيق التفاعلي يعمل كـ موقع ويب مباشر على مستودع GitHub الخاص بك:

1. إنشاء ملف index.html قم بإنشاء مستودع جديد (New Repository) على GitHub باسم earth-sonification ورَفْع هذا الملف داخل المستودع واحفظه باسم index.html.
2. التوجه إلى الإعدادات (Settings) من داخل مستودعك على GitHub، اضغط على تبويب Settings في الأعلى.
3. تفعيل GitHub Pages من القائمة الجانبية اختر Pages، وفي قسم Build and deployment اختر الفرع main ثم اضغط Save.
4. التجربة الحية خلال دقيقة واحدة سيمنحك GitHub رابطاً مباشراً لمشروعك (مثل: https://username.github.io/earth-sonification/) يتيح لأي شخص الاستماع لتجربتك التفاعلية!
